# 循环 2：毛玻璃课程分页器与书角导航移除

## 目标

以合并后的 GitHub 重构版 `main` 提交 `a02c34c` 为基线，把课程页底部固定分页器改成清晰、克制的毛玻璃控件，并完整删除不易发现的书角翻页入口。底部分页器成为普通分段课程唯一的知识点翻页入口，本循环不改变课程内容、知识点拆分或教材页面导航。

## 需求

1. 只在 `codex/loop-02` 修改合并后的重构版；旧桌面项目保持只读，不迁移任何旧 UI 或课程逻辑。
2. 删除 `lecturePrevOverlayBtn` 与 `lectureNextOverlayBtn` 的 HTML，且页面中不得残留同名或替代书角控件。
3. 删除书角导航的 DOM 引用、显隐和禁用状态同步、动画函数、全局 `pointerdown`/`click` 捕获及专属事件处理；不得只用 CSS 隐藏。
4. 删除 `app/style.css` 与 `app/css/runtime-collapsed.css` 中只服务于书角按钮的规则。遇到混合选择器组时，只删除死亡选择器分支，必须保留其他仍在运行的分支。
5. 保留现有 `#learnExplainPager` 及其知识点、跨小节和完成状态数据流，不重写 `moveLearnKnowledgePoint()` 或课程渲染核心。
6. 底部分页器只在普通课程包含至少两个知识点时显示；章节概览、章节概览分栏、隐藏课程页以及零或单知识点课程必须隐藏。
7. 分页器外壳改为中性半透明毛玻璃：背景模糊与适度饱和、细描边、柔和阴影；移除粗黑边、硬偏移阴影和卡通纸张质感。
8. `Prev`、页码和 `Next` 保持稳定尺寸与清晰对比。首个知识点禁用 `Prev`，中间知识点启用双向导航，末个知识点继续沿用既有 `Next topic`/`End` 行为。
9. 保留键盘操作、可见 `:focus-visible` 状态、按钮禁用语义和既有 ARIA 导航语义；触控目标不得小于 44 像素。
10. 桌面与移动端不得出现分页器遮挡正文、超出容器或与问答栏重叠。
11. 更新静态测试、浏览器测试、CSS 探针和视觉基线，使测试明确验证书角已移除及分页器的新行为，不得通过放宽阈值掩盖回归。

## 验收标准

- [ ] `app/` 和相关测试代码中不存在书角按钮 ID、书角专属类、书角事件处理函数或书角动画函数引用。
- [ ] 页面运行时不存在 `#lecturePrevOverlayBtn`、`#lectureNextOverlayBtn`、`.lecture-page-corner` 或 `.page-turner` 元素。
- [ ] 普通课程有两个及以上知识点时显示一个且仅一个底部分页器；零或单知识点、章节概览和隐藏课程页均不显示。
- [ ] `Prev`、`Next`、页码、禁用态、末页跨小节行为与课程状态一致，无双触发或翻两页现象。
- [ ] 分页器在桌面和移动端均呈现毛玻璃效果，文本和图标可读，键盘焦点可见，正文不被遮挡。
- [ ] CSS 删除遵守死亡选择器分支移除规则，其他活选择器集合保持不变。
- [ ] `npm run check`、`npm run test:ui-friction` 及相关课程导航测试通过。
- [ ] CSS 探针不再依赖书角元素，并对分页器的显示、背景模糊、边框、禁用态和稳定尺寸建立有效断言。
- [ ] 浏览器在代表性桌面和移动视口完成截图与交互验收，控制台无新增错误。
- [ ] PR 只包含本循环 UI、测试、设计和证据文件，不包含旧项目遗留功能或课程内容修改。

## 停止与回滚条件

- 任一导航状态发生双触发、跳页、不可返回或跨小节错误时，立即停止视觉调整并先修复行为回归。
- 如果删除混合 CSS 选择器分支导致其他控件 computed style 改变，回滚该次选择器删除并按分支逐条处理。
- 如果移动端分页器遮挡内容，优先调整分页器尺寸与正文预留空间，不恢复书角入口。
- 回滚以本分支提交为单位；不得修改旧桌面项目或恢复已决定舍弃的旧功能。
