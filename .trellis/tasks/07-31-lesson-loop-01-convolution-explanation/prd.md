# 讲解 Loop 01：图解卷积第一版

## 目标

以远端 `main` 提交 `d57ecaf` 为基线，把 `2.4-2 Graphical Understanding of Convolution Operation` 重写为第一版标准化讲解。课程先用两个已确认的口语化比喻建立直觉，再总结图解卷积步骤，通过一个连续 GeoGebra 场景承载教材 Figure 2.7，最后说明卷积在本书中的位置和用途。

本 Loop 只建立可用的第一版，不追求一次完成所有教学细节。后续 Loop 再根据真实学习体验迭代措辞、交互任务、即时测验和更细的教学反馈。

3. 课程正文采用以下顺序：
   - Why：为什么有记忆的系统需要累计历史输入；
   - What：把 `x(τ)`、`g(t-τ)`、乘积和积分逐项映射到直觉；
   - How：解释为什么图解卷积需要翻转、平移、相乘和积分；
   - 步骤总结；
   - Figure 2.7 GeoGebra Demo 与教材检查点；
   - 本书内的用途与前后章节关联。
4. 固定两个比喻，不再更换：
   - 透明水池中分批滴入墨水，用于说明所有历史贡献的叠加；
   - 农田与移动洒水车，用于说明翻转、平移、逐点相乘和积分。
5. 两个比喻只使用自然、口语化文字，不增加墨水池、洒水车或农田插图。抽象解释后立即给比喻，并立即把比喻中的对象映射回数学符号。
6. 正常课程流中不再单独展示教材 Figure 2.7 静态图；Figure 2.7 由现有单一 GeoGebra Applet 变成可拖动的活图。CDN 失败时的降级内容仍可保留静态图和核心公式，不属于正常课程主视觉。
7. GeoGebra 使用一个连续场景完成“认识信号、翻转、平移、观察重叠与输出”；步骤切换不得重建 Applet，拖动 `t` 时重叠面积、当前输出值和 `c(t)` 上的点必须同步。
8. GeoGebra 与课程公式必须按教材 Figure 2.7 的真实幅值修正：
   - `x(t)=u(t+1)`；
   - `g(t)=2e^{-(t+2)}u(t+2)`；
   - `g(t-τ)=2e^{τ-t-2}u(t+2-τ)`；
   - 首次接触为 `t=-3`，接触点面积为 `0`；
   - `c(t)=0`（`t<=-3`），`c(t)=2[1-e^{-(t+3)}]`（`t>-3`）。
9. 步骤总结固定为五步：“固定、翻转、平移、乘积面积、记录扫描”。同时保留教材的省力提示：利用交换律，优先翻转较简单的信号。
10. “运用在哪里”必须回到本书，不写成脱离教材的泛泛应用清单：
    - 第 2.4 节用 `y(t)=x(t)*h(t)` 求 LTIC 系统的零状态响应；
    - 关联前文 Example 2.9 的 RLC 电路；
    - 保留教材明确提到的采样与滤波；
    - 预告 2.4-3 中级联系统的总冲激响应 `h_1*h_2`。
11. 课程正文继续匹配当前英文课程缓存；中文设计稿确定教学含义，正式英文应自然表达该含义，不做生硬逐字翻译。设计、实施和验收文档使用中文；最终 Loop 验收记录提供中英文两部分。
