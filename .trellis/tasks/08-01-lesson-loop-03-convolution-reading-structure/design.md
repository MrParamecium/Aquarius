# 讲解 Loop 03：卷积扫读结构与定向图解设计

## 1. 设计结论

本 Loop 采用已确认的方案 C：每页保留一条短过渡句，再用 2–4 个带大序号的轻量内容岛承载核心信息。正文从连续段落改成短 Bullet，关键词使用跨页一致的语义色；新增视觉只放在第 2、4、6 页，用三张精确的代码原生图解补足变量扫描、操作步骤和教材用途。

这不是一次课程架构重构。正式课程仍由同一份 `2_4-2` 缓存、现有 H2 自动分页、KC block 和 GeoGebra renderer 组成。本轮只改课程正文中的结构化 HTML、课程专属 CSS 和对应定向测试。

## 2. 方案比较

### 方案 A：每个知识点一个独立框

优点是边界最明显；缺点是框太多，学生会不断在小块之间跳跃，视觉噪声接近“一句话一个框”。不采用。

### 方案 B：每页一个大框

实现简单，但文字仍然堆在一起，只是给文字墙加了一层边界，无法改善扫读。也容易让 GeoGebra 和类比图变成卡片中的卡片。不采用。

### 方案 C：过渡句 + 轻量内容岛（采用）

每页用一条无框过渡句建立上下文，再按语义分成 2–4 个内容岛。内容岛采用轻边框、淡底或左侧语义色线，不使用悬浮感重阴影。它既能让学生看到结构，又不会把页面切成大量碎片。

## 3. 信息层级

课程使用两层编号：

```text
页面结构：1 → 2 → 3 → 4 → 5 → 6
页内结构：01 → 02 → 03 → 04（每页重新开始）
```

页面编号表示整节课的学习顺序；页内编号只表示当前页的阅读顺序。第 4 页是特例：整个五步时间线属于一个连续教学视觉，时间线内部用 `01–05` 表示操作步骤，不额外再套 5 个独立内容岛。

每个内容岛包含以下元素中的必要子集：

- 两位大序号；
- 不超过一行的短标题；
- 1–3 条短 Bullet；
- 公式、类比图或微型信号；
- 必要时一条结论或警告。

过渡句只承担“为什么接下来要看这块”的作用，不重复内容岛结论。普通 Bullet 一条只讲一件事；如果一个句子同时包含原因、动作和结果，拆成多个 Bullet。

## 4. 六页正式蓝图

### 第 1 页：Why Convolution Adds the Past

无框过渡句：系统不会在输入结束时立刻忘记它。

1. `01 系统记忆`：过去的一小段输入会留下响应；当前输出是仍然存在的响应总和。
2. `02 墨水池类比`：保留已确认的口语原话与 V2 图片；图片和正文属于同一个内容岛，不再套第二层卡片。
3. `03 映射回公式`：分别说明 `x(τ)`、`g(t-τ)`、乘积和积分；每个映射是一条 Bullet。

### 第 2 页：What the Integral Is Saying

无框过渡句：计算一个 `c(t)` 时，先选定“现在”。

1. `01 核心公式`：单独放大卷积积分；输入、响应与输出使用对应语义色。
2. `02 t 固定，τ 扫描`：正文与数学时间轴组成同一语义区块。
3. `03 快速读法`：每个 `τ` 只问“当时输入多少”“现在剩多少”，相乘后得到一个历史贡献。

时间轴固定显示一个 `t=now` 锚点，用扫描箭头表示 `τ` 沿积分轴移动。游标所在位置向 `x(τ)` 与 `g(t-τ)` 各连一条引导线，最后汇入 `x(τ)g(t-τ)`。它是解释变量角色的静态教学图，不增加拖拽、播放或动画。

### 第 3 页：How the Graphical Procedure Works

无框过渡句：把公式里的动作换成洒水车在农田上的动作。

1. `01 农田与洒水车`：保留已确认类比和 V2 图片；作物密度映射到 `x(τ)`，喷水量映射到 `g`。
2. `02 Flip & Slide`：掉头对应 `g(τ) → g(-τ)`，移动到 `t` 对应 `g(-τ) → g(t-τ)`。
3. `03 Multiply & Integrate`：保留“稀疏庄稼遇到大水”和“茂密庄稼遇到小水”的对照，强调不能只看重叠宽度。

### 第 4 页：Five-Step Checklist

无框过渡句：每次做图解卷积都走同一条路线。

使用手机优先的纵向时间线，不做环形或横向流程。五行从上到下依次为 Fix、Flip、Slide、Multiply、Record。每行包含：两位大序号、动作词、一条主 Bullet，以及能看出当前变化的微型信号。

- Fix：两条信号放到 `τ` 轴，`x(τ)` 固定；
- Flip：展示 `g(τ)` 到 `g(-τ)` 的镜像；
- Slide：展示翻转后信号移动到当前 `t`；
- Multiply：展示重叠部分的逐点乘积与面积；
- Record：把当前面积记录成 `c(t)` 上的一个点。

“利用交换律，优先翻转较简单的信号”放在时间线之后作为一条无框补充句。

### 第 5 页：Figure 2.7 in GeoGebra

无框过渡句：把固定步骤应用到教材 Figure 2.7。

1. `01 教材信号`：分开列出 `x(τ)`、`g(τ)` 与移动边界 `τ=t+2`。
2. 保留现有唯一 GeoGebra Demo，直接作为主视觉，不再套内容岛外壳。
3. `02 First Contact`：`t=-3` 只接触一个点，零宽度意味着面积为 0。
4. `03 输出公式与检查值`：分段公式拆成“条件 + 结果”，`c(-2)` 与 `c(0)` 为短检查点。
5. `04 Common Trap`：红色警告内容岛，只保留“输出是整块面积”和“先翻转再平移”两个错误点。

### 第 6 页：Why This Section Matters in the Book

无框过渡句：同一个卷积方法会在本书中反复出现。

先用一条纵向主线建立统一模型：`x(t)` + `h(t)` → convolution → `y(t)`。主线下方再纵向排列三条互相独立的教材连接；每条连接内部也保持“输入 → 系统 → 输出”的从上到下方向。桌面端可以放宽节点，移动端可以收紧间距，但不能改变流程方向。

1. `01 Example 2.9`：输入电压 → RLC 电路 → 回路电流。
2. `02 Sampling & Filtering`：原始信号 → 滤波器 → 处理后信号。
3. `03 Section 2.4-3`：系统 1 → 系统 2 → 等效系统 `h_1*h_2`。
4. `04 Key Takeaway`：卷积是在计算“所有过去影响加起来后，现在会得到什么”。

该页不使用第一轮被否决的横向三列总览。不同教材连接必须有独立起点、过程和结果，箭头不能跨行，也不能依赖装饰性占位图片解释含义。

## 5. 语义色系统

样式在 `2.4-2` 课程作用域内定义五个课程专属变量：

```text
输入 / x(τ)           #2563eb  蓝色
系统响应 / g(t-τ)     #7c3aed  紫色
动作词                #16876a  青绿色
输出 / 结果           #b45309  琥珀色
警告 / 错误           #dc2626  红色
```

颜色是辅助线索，不替代文字标签、公式符号或箭头。关键词采用“颜色 + 字重”；警告和最终结论可以附淡色背景。每个内容岛最多 3–4 处彩色高亮，连续句子和整段正文不着色。

## 6. 渲染边界

### 6.1 课程缓存

正式英文课程仍保存在现有命中缓存：

`workspace/materials/lesson-cache/2_4-2/new__aquarius_visual_latex_v2.aquarius_visual_latex_v2.en.md`

六个 H2 保持原样，以便现有 `lesson-render.js` 自动分页。内容岛和三张代码原生图解通过受审查的 `KC_BLOCK` 输出语义化 HTML；不修改 Markdown 解析器、自动分页器或 Demo dispatcher。

### 6.2 课程专属结构

新增结构采用统一的 `.convolution-*` 命名和 `data-convolution-*` 标记，至少区分：内容岛、页内序号、语义高亮、扫描时间轴、五步时间线和教材用途流程。它们只在 `[data-lesson-section="2.4-2"]` 下生效，不覆盖通用 `.lecture-note-card` 或其他课程样式。

内容岛不是浮动卡片：使用中性细边界、最多 4px 语义色左边线、淡色背景和不超过 7px 的圆角，不使用重阴影或 hover 位移。类比图、GeoGebra 和图解都不能再被包进第二层卡片。

### 6.3 代码原生图解

三张图解优先使用语义 HTML 与 CSS 布局；微型信号曲线、轴线和连接线允许使用内联 SVG。SVG 必须包含可访问标题或由外层文字说明，并使用稳定 `viewBox`；不把图解导出为 PNG，不引入外部资源、Canvas 或运行时脚本。

图解必须在没有动画的情况下表达完整关系。第 2 页用方向箭头表达扫描，第 4 页用相邻步骤的微型信号差异表达变化，第 6 页用明确节点名和单向箭头表达输入、系统与输出。

## 7. 响应式设计

桌面端仅在以下位置允许两列：类比正文与 V2 图片、第 2 页文字与时间轴。其余流程默认纵向，避免再次出现横向信息过载。

在 `760px` 及以下：

- 所有内容岛内部改为单列；
- 页内序号占独立稳定列或顶部位置，不能挤压正文；
- 时间轴保持完整 `viewBox`，必要时增高而不是缩小文字；
- 五步时间线继续纵向，不改变阅读顺序；
- 第 6 页主线、三条教材流程及每条流程内部都自上而下排列；
- 两张类比图沿用 Loop 02 的完整显示规则；
- 公式允许换行或横向内部滚动，但页面本身不得横向溢出。

固定格式视觉使用 `aspect-ratio`、`minmax()` 或稳定网格轨道，确保 MathJax 完成、图片懒加载和断点变化时不造成明显布局跳动。

## 8. 兼容与失败处理

- GeoGebra CDN 失败时，现有降级内容和教材公式继续工作；新增静态图解不依赖 CDN。
- 如果内联图解样式未加载，核心 Bullet 和公式仍按 DOM 顺序可读；这属于可降级状态，但不能作为视觉验收通过。
- 两张 V2 图片加载失败时继续显示已有 `alt`；本轮不修改静态路由。
- 深色主题不得让语义文字消失；如果现有深色背景对固定色对比不足，只在 `2.4-2` 作用域内增加衬底，不改变五种语义色含义。
