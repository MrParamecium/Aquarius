# 循环 2：毛玻璃课程分页器与书角导航移除

## 状态

适用于分支 `codex/loop-02`，基线是已合并循环 1 的 GitHub `main` 提交 `a02c34c`。

## 目标

将课程页底部固定分页器改成清晰、克制的毛玻璃控件，并彻底删除可发现性差的书角翻页入口。底部分页器成为普通分段课程唯一的知识点翻页入口，本循环不改变课程内容、知识点拆分、教材页面导航或问答栏行为。

## 已确认决策

- 采用完整移除方案，不使用 `display: none` 掩盖旧书角逻辑。
- 删除书角 DOM、事件、动画、状态同步、专属 CSS 和失效测试探针。
- 复用现有底部分页器的数据流和课程核心导航函数。
- 底部分页器只在普通课程包含至少两个知识点时显示。
- 旧桌面项目保持只读，不迁移剩余旧 UI 或课程功能。

## 当前结构

`#learnExplainPager` 由 `app/ui-friction-fixes.js` 维护，读取 `learnKnowledgePoints` 和 `currentKnowledgePointIndex`，并在点击时调用 `moveLearnKnowledgePoint()` 或末页跨小节逻辑。

书角入口由 `#lecturePrevOverlayBtn` 和 `#lectureNextOverlayBtn` 构成。它们在 `app/app.js` 中拥有直接点击监听、文档级 `pointerdown`/`click` 捕获、命中检测、去重和动画逻辑，在 `app/lesson-render.js` 中同步禁用状态，并在两份主 CSS 中拥有大量历史叠加规则。

本循环把这两条路径收束为一条，不重写课程状态或课程渲染引擎。

## 实现边界

### 页面结构

从 `app/index.html` 删除两个书角按钮和 `.turner-content`。保留底部分页器的 `Prev`、页码和 `Next`，继续使用语义化导航容器和现有图标。

### 行为

从 `app/app.js` 删除书角 DOM 引用、命中检测、捕获事件、动画、监听器和状态写入。从 `app/lesson-render.js` 删除书角依赖说明与禁用状态同步。

`app/ui-friction-fixes.js` 继续拥有底部分页器：

- 课程视图隐藏、章节概览或章节概览分栏时隐藏；
- 知识点数少于 2 时隐藏；
- 首个知识点禁用 `Prev`；
- 中间知识点启用双向导航；
- 末个知识点保留既有 `Next topic` 或 `End` 行为；
- 点击后只发生一次导航，不再调用书角动画。

### 视觉

底部分页器使用中性白色半透明表面、背景模糊和适度饱和、一像素半透明描边及柔和多层阴影。内部按钮使用更轻的半透明表面，移除粗黑边、硬偏移阴影和纸张卡通质感。

所有状态都必须保持可辨认：

- 默认态有清晰文字和图标对比；
- 悬停态只做轻微表面与阴影变化；
- 按下态提供轻量位移反馈；
- 禁用态降低强调但仍可读；
- `:focus-visible` 提供独立于悬停的高对比焦点环；
- 按钮触控高度至少 44 像素，文本字距为 0。

分页器保持固定宽高约束，动态标签不得造成布局跳动。移动端可收紧间距，但不能隐藏页码、遮挡正文或与问答栏重叠。

## CSS 删除规则

书角样式跨越 `app/style.css` 与 `app/css/runtime-collapsed.css`，且部分规则与其他控件共用选择器组。因此必须遵守项目 CSS 规范：

1. 以书角 ID 和专属类为选择器令牌定位，不按大段行号删除。
2. 只有全部选择器分支都死亡时才删除整条规则。
3. 混合规则只删除书角分支，其他活分支、声明和媒体条件原样保留。
4. 删除后核对其他活选择器集合不变。
5. 不借本循环清理无关 CSS 或调整其他课程控件。

## 验收门槛

### 门槛 0：干净基线

- 分支为 `codex/loop-02`，HEAD 为 `a02c34c`。
- 修改前工作区干净，旧桌面项目无写入。

### 门槛 1：完整删除

- 运行时代码与相关测试中不存在书角按钮 ID、专属类和专属函数。
- 页面运行时不存在书角元素。
- 没有文档级捕获事件继续尝试处理书角命中。
- CSS 中不存在只服务于书角的规则，混合规则的活分支保持不变。

### 门槛 2：分页器行为

- 两个及以上知识点只显示一个底部分页器。
- 零或单知识点、章节概览、章节概览分栏和隐藏课程页均不显示。
- 首、中、末知识点的按钮状态正确。
- 普通知识点翻页和末页跨小节行为只触发一次。

### 门槛 3：视觉与无障碍

- 桌面与移动端均呈现真实毛玻璃效果，并有不支持 `backdrop-filter` 时仍可读的半透明背景回退。
- 文字、图标、禁用态和焦点态对比清晰。
- 分页器不遮挡正文、不越界、不与问答栏重叠，动态标签不引起布局跳动。

### 门槛 4：回归与证据

- `npm run check` 和分页器相关浏览器测试通过。
- CSS 探针删除失效的书角状态，并新增能区分新旧分页器的有效属性检查。
- 视觉差异只包含已批准的分页器样式变化和书角消失。
- PR 保存桌面/移动截图、交互结果、静态引用清零结果和明确排除项。

## 停止与回滚

发生双触发、跳页、不可返回、跨小节错误或无关控件样式变化时立即停止并诊断。移动端遮挡通过分页器尺寸和正文预留空间修复，不恢复书角入口。

Loop 02 通过独立提交和 PR 合并，可以整体回滚，不影响 Loop 01 已合并的教材材料。
