# 手机端 Show 恢复按钮毛玻璃设计

日期：2026-07-27

## 目标

把手机端课程里的“显示问答”和“返回讲义”两个 Show 恢复按钮统一为与课程底部分页器一致的轻量毛玻璃风格，减少当前米白纸张按钮的厚重感，同时保留清晰、容易发现的入口。

## 视觉方案

- 使用半透明白色背景、`backdrop-filter` 模糊与轻微饱和形成真实毛玻璃层。
- 使用低对比白色描边、内高光和柔和投影，让按钮从讲义或问答背景上稳定浮起。
- 删除虚线内框、顶部胶带装饰和左右旋转，避免纸张标签与毛玻璃分页器混用。
- 保留 `Show` 文字与蓝色方向图标；左右按钮只通过箭头方向表达目标面板。
- 维持至少 `44px` 的触控高度，文字 `letter-spacing: 0`，焦点轮廓继续清晰可见。

## 实施边界

- 只在 `max-width: 900px` 的普通课程单面板状态覆盖两个恢复按钮。
- 复用现有 `#learnChatRestoreBtn`、`#learnExplainRestoreBtn` 和子元素，不修改 HTML 或 JavaScript。
- 不改变桌面端、章节概览、教材模式、按钮显示条件或面板切换逻辑。
- 不修改 GeoGebra 组件及课程分页器。

## 状态

- 默认：半透明玻璃底、蓝色图标、深色文字。
- 悬停：背景略亮、边框略清晰、按钮上移 `1px`。
- 按下：取消上移并轻微收紧阴影，保持反馈但不改变布局。
- 键盘焦点：保留当前高对比 `focus-visible` 外轮廓。

## 验收

- 在 `390x844` 分别检查讲义态与问答态，两个 Show 按钮视觉一致。
- 按钮高度不小于 `44px`，没有横向溢出或文本裁切。
- 讲义与问答双向切换仍通过，GeoGebra Applet、当前步骤、`t` 和 Canvas 不重建。
- 运行移动面板回归、UI friction 测试与 `git diff --check`。
