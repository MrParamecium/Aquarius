## 2. 教材依据

教材为 B. P. Lathi 与 R. A. Green 的《Linear Systems and Signals》第三版。纸质页 178 的 2.4-2 开头说明：

- 图解卷积可以帮助计算复杂信号的卷积积分。
- 图解结果有助于在采样、滤波等问题中直观判断输出。
- 某些信号没有准确数学表达式，只能用图形描述，因此必须用图形卷积。

教材随后强调：

- $c(t)=\int x(\tau)g(t-\tau)d\tau$ 的积分变量是 $\tau$。
- $t$ 在一次积分中只是参数。
- 应当把 $x(\tau)$ 固定，把 $g(\tau)$ 翻转为 $g(-\tau)$，再平移为 $g(t-\tau)$。
- 两者乘积下的面积就是当前的 $c(t)$。

纸质页 179 的 Figure 2.7 展示完整过程，纸质页 180 给出五步总结。原始教材文件：`/Users/chenghaoxiang/Desktop/Linear Systems and Signals Third Edition.pdf`。

## 3. 页面架构

课程打开后先进入顶部的三阶段导航。三阶段属于同一个小节，阶段之间可以直接跳转；每个阶段内部保留自己的分页或题目进度。

```text
章节简介（1页） → 正式讲解（多页） → 练习巩固（多题）
```

### 3.1 阶段一：章节简介

页面标题为“图解卷积”，不再使用大块 `Section Objective` 卡片。页面只保留三条信息：

- **你已经知道**：上一节已经用卷积计算 LTI 系统的零状态响应。
- **这一节解决什么**：公式里的翻转、平移和积分，在图上分别代表什么。
- **学习路线**：卷积是什么 → 为什么需要图解卷积 → 如何计算 → GeoGebra 演示 → 练习。

主按钮进入“正式讲解”。

### 3.2 阶段二：正式讲解

讲解页顺序固定为：

1. **卷积是什么？**：输入、系统响应、输出，以及重叠面积与当前输出的关系。
2. **为什么需要图解卷积？**：复杂积分、只有图形没有公式的信号，以及采样和滤波中的直观判断。
3. **如何计算：先翻转，再平移**：$g(\tau)\rightarrow g(-\tau)\rightarrow g(t-\tau)$。
4. **如何计算：相乘并计算面积**：重叠、乘积、面积和当前 $c(t)$。
5. **教材 Figure 2.7 交互演示**：用 GeoGebra 重现固定、翻转、平移、重叠和输出曲线。
6. **卷积在本章中的作用**：零状态响应、LTI 系统、滤波与采样的后续联系。

阶段内显示轻量进度，如“讲解 1 / 6”，并提供上一页、下一页。

### 3.3 阶段三：练习巩固

练习阶段独立于讲解分页器，但保留同一小节上下文。题目顺序为：

1. 判断哪条信号固定、哪条信号移动。
2. 判断两个信号开始重叠的时刻。
3. 用 GeoGebra 完成一次完整卷积。
4. Quick Check 检验关键概念。

## 4. 视觉规范

### 4.1 编号采用 A/C 混合规则

- **普通概念页使用 A：页边编号**。编号放在内容左侧，不包裹成厚重的大卡片；内容以教材式纵向排版为主。
- **真正有先后关系的操作页使用 C：连续时间轴**。时间轴节点表示步骤顺序，适用于“翻转 → 平移 → 相乘 → 积分”等过程。
- 概念页不强行使用时间轴，避免把“是什么”和“为什么”误读成操作步骤。

### 4.2 内容块边界

- 删除当前大号 `01/02/03` 内容框的厚重视觉。
- 普通讲解使用细分隔线、页边编号、短标题和项目符号。
- 需要突出一组知识点时使用轻边界内容岛：细边框、窄色条、小型书签编号，不使用大面积阴影。
- 过渡句不单独放入框中；定义、关键结论、步骤、例子和公式才进入内容块。
- 每个内容块只承载一个清晰任务，避免卡片套卡片。

### 4.3 文字层级

- 页面标题使用章节级字号；内容标题明显小于页面标题。
- 解释文本优先拆成项目符号。
- 关键术语、变量和结论使用颜色标记，但同一页面不超过三种语义颜色。
- 公式保持独立行并允许横向滚动，避免窄屏溢出。

## 5. 导航与交互

### 5.1 顶部阶段导航

- 三个阶段使用分段导航：`章节简介 | 正式讲解 | 练习巩固`。

### 5.3 翻页动画

- 页面锁定时间同步控制在约 180ms，避免重复点击造成状态错乱。
- `prefers-reduced-motion` 下直接切换，无动画。
