5.3-3 Inverse Systems
If H[z] is the transfer function of a system S, then Si , its inverse system, has a transfer function
Hi [z] given by
                                                      1
                                            Hi [z] =
                                                     H[z]
This follows from the fact the inverse system Si undoes the operation of S. Hence, if H[z] is placed
in cascade with Hi [z], the transfer function of the composite system (identity system) is unity. For
example, an accumulator whose transfer function is H[z] = z/(z − 1) and a backward difference
system whose transfer function is Hi [z] = (z − 1)/z are inverse of each other. Similarly if
